# ארכיטקטורת המרה (CRO) — כהן ושות׳

עודכן: 13.10.2026 · מחליף מסמך CALLBOT ישן באותו נתיב.

## יעד
פניות לייעוץ (טופס + `tel:`) — לא מכירה אונליין.

## KPIs (סקריפט 4)
| מדד | יעד ראשוני |
|---|---|
| לידים / חודש | 15–20 (baseline ייאסף ב־30 יום ראשונים) |
| השלמת טופס | % ממבקרים ב־`/contact#lead` |
| הקלקות tel | GA4 אחרי consent |
| CTA ראשי | `cta_click` ב־dataLayer |

## משפך
1. **Hero** — מצב + ותק + CTA ייעוץ  
2. **דלתות תחום** — משפחה / עבודה / נדל״ן → מעביר `practiceArea`  
3. **למה אנחנו / תהליך** — הסרת חשש לפני הטופס  
4. **טופס / tel** — המרה  
5. **Thank-you** — `noindex`, בלי PII ב־URL, cookie ack בלי מייל  

## מה לא בונים בהשקה
Calendly · Pixel מטא · מייל אוטומטי לפונה · WhatsApp אוטומטי · סליקה · A/B חי בלי GA4 יציב.

## ביקורות Google
רק אחרי תיקים אמיתיים ובאישור הלקוח — בלי review gating ובלי הטבה תמורת ביקורת. עד אז אין מקטע המלצות מזויף באתר.
