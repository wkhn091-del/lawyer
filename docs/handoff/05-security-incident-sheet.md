# כהן ושות׳: דף אבטחה ואירועים

עמוד אחד. כדאי להדפיס או לשמור במקום שקל למצוא ביום לחוץ.

## ממה האתר מוגן
- **בוטים וספאם:** Cloudflare Turnstile, שדה מלכודת, והגבלת שליחות לפי חיבור ולפי מייל.
- **הזרקת קוד (XSS):** CSP עם nonce חוסם סקריפטים שלא אושרו.
- **הטמעה באתר זר (Clickjacking):** אי אפשר להטמיע את האתר ב-iframe.
- **שליחות מזויפות:** כל שליחה נבדקת שהגיעה מהאתר עצמו (Origin).
- **דליפת מידע:** HTTPS; פרטי לידים לא נשמרים באתר ולא נשלחים לכלי ניטור; אנליטיקס רק אחרי הסכמת עוגיות.
- **תקלות שקטות:** Sentry לשגיאות שרת; `/api/health` לניטור זמינות.

## מה באחריות המשרד
- **אימות דו-שלבי (2FA)** על Google (GTM/מייל), Vercel (אם יש גישה), GitHub (אם יש), Cloudflare, רשם הדומיין, Sanity Studio.
- **סיסמה ייחודית** לכל מערכת, במנהל סיסמאות.
- **משתמש אישי** לכל מי שיש גישה — לא משתפים חשבון.
- **עובד עוזב:** מודיעים באותו יום ומבטלים גישות + מסובבים מפתחות.
- **קבצים:** לא פותחים CSV/מייל מצורף ממקור לא מוכר (סיכון נוסחאות).

## אירוע אבטחה או באג?

| אירוע אבטחה: מתקשרים מיד | באג: כותבים במייל תמיכה |
|---|---|
| משתמש לא מוכר ב-GTM / Vercel / GitHub / Studio | הטופס מציג שגיאה |
| תוכן באתר שלא פרסמתם | עמוד נטען לאט או נשבר |
| מייל «אבטחה» שמבקש קוד או התחברות | ליד הגיע בלי חלק מהשדות |
| מאות לידים מוזרים בבת אחת | קישור שבור |
| התראה על כניסה ממדינה אחרת | תקלה תצוגתית במובייל |
| מחשב/טלפון עם גישה למערכות נגנב או אבד | |

## חושדים בפריצה? 4 צעדים
1. **לא מוחקים כלום** — שומרים עקבות (מייל, ליד, משתמש).
2. **מנתקים:** מחליפים סיסמה במערכת שנפגעה + «התנתקות מכל המכשירים».
3. **מתקשרים לסוכנות מיד** ([למילוי — טלפון חירום]), ואז מייל עם מה ראיתם, מתי, וצילומי מסך. חוקרים חיצוניים: `avi@cohen-law.co.il` (גם ב-`security.txt`).
4. **אנחנו מטפלים:** סיבוב מפתחות, בדיקה מה נחשף, תיקון, עדכון בכתב. אם נחשף PII — ליווי מול רשות הגנת הפרטיות לפי חוק.
